DRAMAVERSE — K-DRAMA STORYBOOK PROJECT
======================================

HOW TO RUN
1. Extract the ZIP.
2. Open the extracted folder in VS Code (File > Open Folder).
3. Open index.html and choose "Open with Live Server" if installed.
   You can also double-click index.html to open it in a browser.

FOLDER STRUCTURE
- index.html          Main library and 30 book cards
- style.css           One external stylesheet
- script.js           One external JavaScript file
- stories/            30 individual story pages, one chapter each
- images/covers/      SVG cover fallbacks and available local K-drama poster photos
- images/scenes/      30 local SVG supporting illustrations

FEATURES
- Search and genre filtering
- Dark/light theme toggle
- Book details popup
- Like buttons
- Reading progress indicator
- Navigation between library and story pages
- Responsive layout for desktop and mobile

NOTE
This is an original fan-made school project. The chapters are fictional,
original writing inspired by broad themes of the supplied titles. They are
not official scripts, episode transcripts, or representations of actual plots.
Some supplied titles were repeated; each list entry was retained as a separate
storybook so the project has 30 covers as required by the assignment.
